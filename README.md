### 🖥️ What Does This App Do?

jevlike is a small, powerful program that takes a piece of text (like a question or instruction) and a list of possible answers. It then gives you a probability score for each option—showing which one is most likely the right choice. This works in one pass, meaning it's very fast compared to older methods that write answers word-by-word.
